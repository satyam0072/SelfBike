# Bihar Dream Bikes Pvt Ltd — Website

A responsive front-end website for a self-drive bike rental business in Patna, Bihar.

## Included
- Modern landing page using the supplied fleet photo and logo
- Bike collection cards
- Booking modal with date/time selection and rental estimate
- Local booking collection/dashboard using browser localStorage
- Responsive mobile layout
- No backend required for the demo

## Before publishing
Replace the sample bike names/prices with your actual fleet.
Add the exact pickup address, phone/WhatsApp number, business hours and payment/database integration.

## Run
Open `index.html` in a browser, or host the folder on any static hosting service.
